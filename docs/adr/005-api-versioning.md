# ADR 005: API Versioning

## Статус
✅ Прийнято

## Контекст
Потрібно підтримувати зворотну сумісність.

## Рішення
Дві версії API:
- **v1**: `app/api/v1/` — legacy, прямі SQLAlchemy виклики
- **v2**: `app/api/v2/` — Use Cases based, DI, events, cache

Поступова міграція з v1 на v2.

## Наслідки
✅ + Зворотна сумісність
✅ + Поступова міграція
⚠️ - Два набори роутерів
