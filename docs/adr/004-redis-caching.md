# ADR 004: Redis Caching

## Статус
✅ Прийнято

## Контекст
API v2 має endpoints для списків товарів і категорій.
Без кешу кожен запит робить SELECT до БД.

## Рішення
Redis кеш через ICacheService інтерфейс:
- TTL: продукти 60s, категорії 300s
- Інвалідація при POST/PUT/DELETE
- Fallback: без Redis працює без кешу

## Наслідки
✅ + Швидкість: відповіді з кешу за 1-5ms
✅ + Прозорість: fallback без Redis
⚠️ + Потрібен Redis сервер
